# text-extractor
This is a modern, lightweight GUI application designed to extract text wrapped in double quotes from files and replace them in template files.

## Features
- **Multilingual Support:** Easily add new languages by creating simple JSON files in the `locales` folder.
- **Light/Dark Mode:** Switch between themes seamlessly with a single click.
- **Drag & Drop:** Drag files directly into the application for a faster workflow.
- **Validation:** Built-in structural validation to detect and report quote-related errors.
- **Live Preview:** View a preview of selected files before applying changes.

## How to use
1. Run the application.
2. Select your preferred language from the dropdown menu.
3. Toggle the theme (Light/Dark) as needed.
4. Select your files or drag and drop them into the interface.
5. Perform your desired action (extract or replace) and save the output.



  # ابزار پردازش متن
  
این برنامه یک ابزار گرافیکی مدرن و سبک برای استخراج متن‌های داخل دبل کوتیشن از فایل‌ها و همچنین جایگذاری آن‌ها در فایل‌های قالب.

## قابلیت‌ها
- **چندزبانه:** پشتیبانی از زبان‌های مختلف با قابلیت اضافه کردن آسان زبان جدید از طریق فایل‌های JSON.
- **تم تیره و روشن:** قابلیت تغییر تم برنامه تنها با یک کلیک.
- **کشیدن و رها کردن (Drag & Drop):** امکان کشیدن و رها کردن فایل‌ها به داخل محیط برنامه برای سرعت بیشتر.
- **اعتبارسنجی زنده (Validation):** بررسی ساختار فایل و نمایش خطاهای مربوط به کوتیشن‌ها.
- **پیش‌نمایش زنده (Live Preview):** مشاهده پیش‌نمایش فایل‌های انتخاب شده قبل از پردازش نهایی.

## نحوه استفاده
1. برنامه را اجرا کنید.
2. از منوی کشویی زبان مورد نظر خود را انتخاب کنید.
3. با دکمه تم، ظاهر برنامه را (تیره یا روشن) تنظیم کنید.
4. فایل‌های خود را انتخاب کرده یا به داخل برنامه بکشید (Drag & Drop).
5. عملیات مورد نظر (استخراج یا جایگذاری) را انجام دهید و خروجی را ذخیره کنید.
